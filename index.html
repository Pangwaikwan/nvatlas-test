Learning report

What the noun-to-verb shift reveals

This study asks how subtitle translators turn abstract English nominalisations into compact Chinese predicates. It is an exploratory corpus analysis, not a claim about all translation.

OriginBackgroundGapQuestionsMethodAnalysisConclusionReflection

Origin

The starting file was a 500-pair subtitle sample that paired each English sentence with a Chinese sentence, an abstract English nominal, and a Chinese verb. Its striking pattern was the shift from a noun-centred English phrase such as “give permission” or “pay attention” to a compact Chinese predicate.

Background

English academic and formal registers often prefer nominalisation: an action is packaged as a noun and joined to a light verb. Chinese can make the same event available as a verbal predicate. Subtitle constraints make the difference visible because screen space and reading speed favour compact wording.

Gap

Existing bilingual tools help users search sentences, but they often present isolated translations without showing which nominal forms repeatedly become verbs. The supplied CSV also lacks explicit provenance URLs and manual-check marks, so this project treats source traceability and verification status as part of the analysis rather than hiding them.

Questions

  1. Which morphological categories dominate the sample, and how consistent are their Chinese renderings?
  2. Which nominals have the widest range of verb translations?
  3. Where should a human reviewer start when the source metadata is incomplete?

Method

I preserved the original CSV and generated a JSON derivative. Categories were assigned by an explicit suffix rule: -tion/-sion as action/process, -ment as result/state, -ance/-ence/-ancy/-ency as quality/condition, and all others as the comparison group. A term is “varied” when the filtered data contains more than one Chinese verb for it. Source, category, and human_check fields are exposed in the site. No upstream URLs were supplied, so every human_checked value is honestly marked “no”; checking 50 entries against originals remains required before submission.

Important: suffix classification describes form, not meaning. A word such as “attention” can name a state or an action depending on context. The category is a reproducible starting point, not a semantic ground truth.

Sampling method cannot be reconstructed from the supplied file because it contains no extraction script, random seed, rejected-candidate count, or upstream sentence URLs. The report records that limitation.

Analysis

The sample is dominated by action/process nominals (317 of 500), followed by quality/condition (84), result/state (70), and other forms (29). This is partly a consequence of the suffix rules and English nominalisation patterns, not evidence that Chinese translators “prefer verbs” in general.

Variation is concentrated in high-frequency terms. Attention has 45 records and four Chinese renderings; permission has 17 records and five; performance has 11 and five. These are better candidates for close reading than rare terms with a single example.

The most frequent Chinese verbs in the sample are 注意 (42), 允许 and 保护 (12 each), 解释 and 讨论 (8 each). These counts show repetition across the filtered corpus, but they do not establish a universal translation rule.

The visualisations all recalculate from the current filters. A category selection changes the totals in Category to rendering pattern, Nominal-to-verb network, Bilingual KWIC, and the data table together.

Conclusion

The corpus makes a simple but useful pattern visible: English nominal forms are often rendered by Chinese predicates, and common nominal types account for much of the variation. The site supports checking that claim at record level rather than relying on a summary statistic alone.

Reflection

The hardest part was not drawing charts but deciding what the file could support. Without upstream URLs, a sampling seed, or manual-check marks, the data cannot be presented as fully verified. I would rebuild the corpus collection pipeline first, record every source sentence and retrieval date, and manually check 50 entries before expanding the codebook. AI was useful for structuring and coding the explorer, but it could not replace source verification or decide meaning in context.

Codebook

Four transparent starting categories

These categories classify the English nominal's surface form. They are intentionally mechanical so another reviewer can reproduce every assignment.

Decision rule

Apply the rules from top to bottom. Match only the ending of the supplied English_Nominal. Do not infer the category from the Chinese verb, because doing so would mix form and translation behaviour.

Positive example

decision ends in -sion and is labelled Action or process. appointment ends in -ment and is labelled Result or state.

Negative example

dance does not match any target suffix and is placed in Other nominal form, even though it can describe an action.

Boundary case

performance ends in -ance, so the mechanical rule assigns it to Quality or condition. Semantically it can also mean an event; the form-based rule keeps the classification stable.

AI Use Declaration

How AI contributed

Tools used

OpenAI Codex in the ChatGPT desktop app, used as a coding and analysis agent. The underlying model version was not exposed in the interface.

What AI did

AI profiled the CSV, proposed the suffix codebook, generated the derived JSON, wrote the HTML/CSS/JavaScript, and drafted the report structure. I retained the original source and can inspect the generated rule in scripts/build_data.py.

What was checked

The input file's count, unique IDs, field completeness, and target-term containment were checked programmatically. Manual verification against upstream subtitle sources has not yet been completed because those sources and URLs were not supplied.

What AI could not do

AI could not verify the original subtitle wording, recover an upstream sentence URL, or decide the author's own sampling seed. Those gaps are marked in the interface rather than filled with invented values.

Example prompt

“Build a static corpus explorer that satisfies the brief, but do not invent source metadata or claim that entries were manually verified. Surface the missing provenance in the interface and report.”

One thing AI got wrong

The first interpretation of “category” could have treated semantic meaning as if it were directly recoverable from the data. A mechanical suffix rule makes the assumption explicit: it can be audited, but it is not semantic truth. The interface and report now say so.
